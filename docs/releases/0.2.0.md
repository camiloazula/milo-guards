# milo-guards 0.2.0

A minor release with security fixes, a new guard, and more of what a guard
can be told about the machine it guards. Every detail is in
[the changelog](../../CHANGELOG.md#020-2026-11-26); this page is what a
caller needs to know to upgrade.

## Upgrade

- Move your requirement from `"0.1"` to `"0.2"`. No 0.1 release carries the
  security fixes.
- The crates declare Rust 1.90 (`rust-version`); 0.1.4 declared 1.99.
- Some answers are more serious than 0.1.4's: the guards now read more
  commands, paths and spellings for what they do. A line that was `safe`
  may now be `delete`, `read_secret`, `overwrite`, `unknown` or
  `unreadable`. Of the 2,934 everyday commands the guards are measured on,
  2,908 are still `safe` (a false-alarm share of 0.9 %).

## Security fixes

- The code reader holds every reading of Python and JavaScript to a bounded
  amount of work, counted as the parser goes and never by a clock, and reads
  no code through a syntax error. Before, crafted code could keep a call to
  `read`, `understand`, or the shell guard's `classify` of a line with inline
  code, from returning.
- The guards judge more lines as risky that they judged safe: commands a
  launcher, a variable or an option hands a program; paths written for
  another system, through a share of this machine, or in more spellings;
  downloads and uploads by where they land and what they send; hook
  installers; programs that read their words from a file; and lines holding
  a NUL or a terminal control character.

The advisories are linked from this release's page on GitHub.

## A deliberate limit: code of at most 3 KiB

The code reader reads at most 3 KiB of code (`milo_guards_code::MAX_LEN`,
64 KiB in 0.1.4). Longer code is not read: the script guard calls it
`unreadable`, and the shell guard calls the inline code of such a line
`unknown`. That is the safe answer, but most real scripts are longer, so the
script guard judges few whole files act by act in this release. A later
release raises the limit.

## New

- **`milo-guards-script`**: a guard for the Python and JavaScript an agent
  runs directly, through a code tool with no shell line around it
  (`judge(Language, code, &Paths)`, also `milo_guards::script`).
- **Where a finding is**: the shell guard's `locate` gives each finding with
  the bytes of the line it is about.
- **Secrets the caller names**: `Paths::with_secrets` names files and folders
  that hold a secret, and a read of one is a finding.
- **Drives and links**: `Paths::with_drive_mounts` and the Windows home on
  WSL place a path through a mounted drive where it lands, and
  `Paths::with_links` lands a path through a link the caller resolved where
  it points.
- **Addresses**: the URL guard's `judge_address` judges an IP address a
  fetch resolved or connected to.

## Not in this release

Ruby, Perl, PHP and Lua given inline are still `unknown`
([#305](https://github.com/camiloazula/milo-guards/issues/305)).
